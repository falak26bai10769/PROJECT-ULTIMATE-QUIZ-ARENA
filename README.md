# Ultimate Quiz Arena

## Project Description

Ultimate Quiz Arena is a beginner-friendly, interactive command-line quiz game developed using Python. The project combines quizzes, mini-games, power-ups, achievements, XP, coins, player statistics, and a session-based leaderboard into one application.

The project is designed to demonstrate the practical use of basic Python programming concepts such as variables, lists, dictionaries, functions, loops, conditional statements, input validation, randomization, and program control.

The entire application runs through the terminal and does not require a database, SQL, file handling, or external packages.

---

## Features

### 1. Multiple Subjects

The quiz contains questions from four subjects:

- Python
- Mathematics
- Science
- General Knowledge

Each subject contains questions at three difficulty levels.

### 2. Difficulty Levels

The available difficulty levels are:

- Easy
- Medium
- Hard

The player can select a subject and difficulty before starting a normal quiz.

The current question bank contains 36 questions in total.

---

## 3. Quiz Modes

The project provides several quiz modes.

### Classic Quiz

The player selects a subject and difficulty and answers a set of questions.

### Rapid Fire

A faster quiz mode where the player answers a smaller set of questions and receives rewards for correct answers.

### Survival

The player attempts to continue answering questions while managing a limited number of lives.

### Daily Challenge

The player can complete a special challenge during the current session and receive additional rewards.

### Boss Battle

The player attempts a challenging quiz round. Successful performance provides bonus score, XP, and coins.

### Tournament

The tournament contains multiple quiz stages and provides additional rewards after completing the stages.

### Category Mix

Questions are selected from different subjects and difficulty levels, creating a mixed quiz experience.

---

## 4. Game Hub

The Game Hub provides three additional mini-games:

### Quick Math

The player solves a randomly generated mathematical calculation.

### Number Hunt

The player attempts to identify a randomly generated number.

### Rock Paper Scissors

The player plays Rock Paper Scissors against the computer.

The mini-games provide an alternative to the normal quiz and can contribute to the player's game statistics and rewards.

---

## 5. Power-Ups

Players receive a collection of power-ups that can be used during quizzes.

The available power-ups are:

- 50/50
- Hint
- Phone
- Skip
- Double
- Shield

Power-ups have limited quantities.

The Arena Shop can also be used to obtain additional power-ups using coins.

---

## 6. XP and Level System

The game tracks the player's XP throughout the session.

XP is earned through different quiz activities and special modes.

When enough XP is collected, the player's level increases.

The level system provides a simple way of tracking player progress during the game.

---

## 7. Coins

Coins are used as the in-game currency.

Players can earn coins through:

- Quiz performance
- Special quiz modes
- Mini-games
- Rewards
- Achievements

Coins can then be used in the Arena Shop.

---

## 8. Arena Shop

The Arena Shop allows the player to use coins to obtain power-ups.

The available shop options include:

- 50/50
- Hint
- Phone
- Skip
- Double
- Shield

The shop also contains a Risk and Reward option where the player can choose a risk level for a possible reward.

---

## 9. Player Statistics

The Player Stats section displays information about the current player's performance.

It can show information such as:

- Player name
- Score
- XP
- Level
- Coins
- Correct answers
- Wrong answers
- Questions answered
- Current streak
- Best streak
- Quizzes played
- Mini-games played
- Boss wins
- Tournament wins
- Daily Challenge status
- Perfect rounds
- Power-up inventory

These statistics are maintained during the current program session.

---

## 10. Streak System

The game tracks the player's answering streak.

The following are maintained:

- Current streak
- Best streak
- Correct answers
- Wrong answers
- Total questions

A correct answer increases the current streak, while an incorrect answer resets it.

The best streak achieved during the session is also recorded.

---

## 11. Achievements

The game includes an achievement system that rewards different types of progress and performance.

Achievements can be earned for activities such as:

- Completing the first quiz
- Answering many questions
- Maintaining a strong streak
- Playing multiple quizzes
- Winning a Boss Battle
- Playing mini-games
- Completing a perfect round
- Collecting coins
- Completing a tournament
- Reaching high scores
- Achieving good accuracy
- Becoming an all-round player

The Achievements section allows the player to view the achievements earned during the session.

---

## 12. Session Leaderboard

The project includes a leaderboard that displays player scores.

The leaderboard is session-based.

Player scores are stored in memory while the program is running and are not permanently stored in a file or database.

Therefore, the leaderboard data is cleared when the program is closed.

---

## 13. Arena Guide

The Arena Guide provides basic instructions about the game.

It explains the main features available in the program, including:

- Quiz modes
- Game Hub
- Power-ups
- Arena Shop
- Player Stats
- Achievements
- Leaderboard

This helps new players understand how to use the application.
